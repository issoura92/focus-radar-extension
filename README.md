# 🚀 Focus Radar – رادار التركيز

> أداة ذكية لمساعدتك على التحكم في وقتك، تقليل التشتت، وزيادة الإنتاجية.

---

## 🧠 فكرة المشروع

**Focus Radar** هي إضافة لمتصفح Chrome تقوم بمراقبة الوقت الذي تقضيه على المواقع المشتتة (مثل YouTube، TikTok، Facebook...)
وعند تجاوز الحد اليومي، يتم **حظر الموقع تلقائيًا** وتحويلك إلى تجربة مفيدة بدل إضاعة الوقت.

---

## ✨ الميزات

* ⏱️ تتبع وقت الاستخدام لكل موقع
* 🚫 حظر تلقائي بعد تجاوز الحد اليومي
* ⚡ حظر فوري بدون إعادة تحميل الصفحة
* 🎯 نظام تحذير قبل الوصول للحد
* 📊 لوحة تحكم تعرض:

  * مدة الاستخدام
  * عدد الزيارات
  * الأحداث (تحذير / حظر / فك الحظر)
* 🔓 إمكانية فك الحظر يدويًا
* 🎨 تصميم حديث وواجهة سهلة الاستخدام
* 🧩 يعمل بدون أي مكتبات خارجية (آمن ومتوافق مع Chrome CSP)

---

## 🧪 كيف يعمل؟

1. يقوم الإضافة بمراقبة التبويب النشط
2. يتم حساب الوقت لكل موقع محدد
3. عند الوصول إلى الحد:

   * يتم إنشاء "Lock"
   * يتم تحويل المستخدم تلقائيًا إلى صفحة الحظر
4. يتم فك الحظر بعد انتهاء المدة

---

## 🖥️ التثبيت (يدوي)

1. قم بتحميل المشروع:

   * من GitHub → **Download ZIP**
2. فك الضغط (Extract)
3. افتح Chrome واذهب إلى:

   ```
   chrome://extensions
   ```
4. فعّل:
   👉 Developer Mode
5. اضغط:
   👉 Load unpacked
6. اختر مجلد المشروع
